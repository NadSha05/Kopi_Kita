# Kopi Kita

Aplikasi pemesanan kopi dengan 3 tampilan: Beranda, Form Pesan, Ringkasan.

## Cara menjalankan
1. Buka terminal di folder `kopi_kita` ini.
2. Buat folder platform (android, ios, web, windows): `flutter create .`
3. Ambil dependensi: `flutter pub get`
4. Jalankan: `flutter run`

Catatan: `flutter create .` tidak menimpa folder `lib/` dan `pubspec.yaml` yang sudah ada.
